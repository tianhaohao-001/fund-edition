## 两分半演示

现场可先问「我批准了 60/40，为什么现在还持有全部模拟现金？」，让评委在 VWELX 同一回执上核对授权、11 月 19 日定价日期和零成交，再倒回下表的自然语言组队流程。网页首访保留原有教学顺序。[评委导览](https://morrowfolio-team-studio.wavyboot13.chatgpt.site/judges.html)

| 时间 | 操作与证据 |
| --- | --- |
| 0:00–0:30 | 用新访客打开网页，与 Maya 说出一个投资想法，校对后发送。当场展示实际回复或失败提示。 |
| 0:30–1:05 | 在工作室确认蓝图，点一位同事、看分工，再看一次投委会已保存的真实消息与独立执行结果。回看时应明确标注先前录制。 |
| 1:05–1:50 | 在基金广场按名称或代码打开 VWELX，查公开方法、实际代理与 23 季留出误差。将固定历史对照与该基金团队今天的决定分开展示。 |
| 1:50–2:15 | 打开当期 AI 决策及各席回执，展示用户何时授权、适用交易窗口及成交或等待原因。现场尚无有效报价时保留等待状态。 |
| 2:15–2:30 | 展示构建记录、实际可审阅的模型回执和已获得的用户试用证据。 |

第三版公开卡提供了另一条更短的现场路径：从工作室让 Maya 根据一个投资想法招募团队，或从基金馆直接点开巴菲特风格研究的第四场会议。两位分析员和一名经理前三次持现，第四次决定买入，独立引擎在下个交易日开盘模拟成交。可以当场打开当期证据，问经理为何改变判断。[正式工作室](https://fund-edition-web-production.up.railway.app/studio?lang=en-US) · [直接打开第四场会议](https://fund-edition-web-production.up.railway.app/funds?id=buffett&decision=buffett-review-4&lang=en-US)

第一批试用对象是希望先验证规则再承担风险的自主投资者。让首次使用者不经提示完成一次授权和对照，并说出哪个规则拦截了成交。记录完成数、能正确解释的用户数与再次运行数，始终保留分母。需要用户同意才引用其原话。试用、购买意向和模拟现金按不同证据处理。 [产品与市场判断](fund-design.md)
