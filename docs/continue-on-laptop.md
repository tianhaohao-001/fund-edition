权威源码位于台式机的 C:\Users\rocks\Documents\Codex\Projects\shared-workspace\Fundroom。在笔记本 Codex 选择远程主机 **codex-home**，再打开该目录，即可继续编辑同一份文件。在「此电脑」打开同一路径会进入笔记本自己的快照。两份本地目录和 SQLite 各自独立。11 月 18 日从台式机只读探测笔记本 SSH 超时，笔记本当前的快照版本尚未核实。

## 打开台式机上的现场演示

本轮桌面审阅地址为[动景大厅](http://127.0.0.1:3386/?lang=zh-CN&lobby=motion#/)和[会员权益](http://127.0.0.1:3386/membership.html?lang=zh-CN)。笔记本通过既有私网 SSH 转发可打开台式机上相同的页面。

~~~powershell
ssh -NT -o ExitOnForwardFailure=yes -L 127.0.0.1:3386:127.0.0.1:3386 codex-home
~~~

转发运行时在笔记本打开同一网址，账户和模拟账本均由台式机服务提供。笔记本上旧启动器可能仍检查旧端口，手动转发可以直接连接新版。

台式机服务若尚未启动，可在共享根执行以下命令。此模式使用回环 3386、基金馆的独立审阅数据库和本机已配置的模型凭据，券商下单关闭。3365 仍可用于此前的演示。

~~~powershell
.\dev.ps1 -GalleryReview
~~~
