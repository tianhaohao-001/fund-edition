2026-11-18，开发总监。现场网页使用台式机的本机模拟账户。以下各项记录用户做了什么，以及一次演示足以证明什么。后续发布负责人以实际运行补记版本和证据。

| 一句话能组队吗？ | 全新访客提出自己的投资想法，线上经理先识别目的，再给出五席蓝图，页面停在待确认状态。团队的另一场真实审议显示逐席发言、交接与独立执行结果，审核样例最终持有现金。[建团回执](../release/review-web/guided-team-blueprint.json) · [投委会回执](../release/review-web/meeting-studio-qa.json) | 真人使用自己的麦克风开口、听到回答、追问、再手动确认，是单独一项体验验收。 |

| 团队现在知道什么、我批准了什么？ | 总监采纳了运营岗提出的时点规则。研究、风险及经理的真实调用、用户授权、行情发布和独立账本余额，必须能在同一个案例中逐项对应。下一完整交易窗口未结束时，页面应保留待执行状态。 | 放行依据由运营岗实测和发布岗交叉复查补入下方；当期尚未发布的价格不能写成已成交。 |
| 账本和我的授权可靠吗？ | 独立复算 720 次模拟提案，检查成交、持有、限额与过期。撤回卖出许可时历史调仓曾绕过检查，现已修复。另修复了两股各 64.01 美元恰好顶到限额时的误拒。八个并发重复请求仅记一张回执。[执行核对](execution-audit.md) | 券商接入的下单边界使用替身验证。真实资金演示另需账户、独立授权及接入验收。 |
| 数据和账户能带走吗？ | 网站区分发行人净值、交易所收盘和固定历史数据，保留各自日期。邮箱账户可继承访客模拟盘，登录同一后端能恢复记录。[日终数据](market-data.md) · [网页账户](accounts.md) | 两台电脑各自独立启动 SQLite 时持有不同的数据库；通过同一台式机后端继续最直接。 |
| 谁听到、谁说话、听错了怎么办？ | 浏览器拒绝麦克风后会把焦点交给文字框并保留草稿。旧实测中，合成中文音轨经本机 Whisper 和真实经理跑通，但把「适中」听成「事终」。已交语音岗复现，用户可以先校对。[权限实测](../release/review-web/guided-voice-permission.json) | 语音回调、实际转写、触发播报以及人耳听感分别记录，不能以单一状态代表全部。 |
