# 中文与 English

从大厅的「设置」选择中文（`zh-CN`）或 English（`en-US`）。设备使用 `morrowfolio.language` 保存选择，没有有效记录时使用中文。工作室、团队、组合、专业模式、基金广场及安装帮助共用 `web/i18n.mjs`。券商与离线独立页也读取同一个选择，离线页的语言模块只作为静态资源缓存。

选择语言不会调用交易或基金确认接口。切换会保留尚未发送的消息、买入金额、授权表单和已有账户。已有聊天、用户名称、引用内容及用户导入资料不自动翻写。新 AI 请求携带明确的 `language`，后端通过该语言约束新回复；识别与朗读也跟随当前选择。普通 AI 入口仍需 HarnessRouter，配置缺失时明确提示连接问题。

基金目录保留一份公开资料：中文字段与 `localized['en-US']` 英文资料共用标的 ID、官方链接、规模、日期和交易算法。第一方策略、职责、风险、研究状态和计算假设按语言显示，不通过对最终 HTML 的文字替换实现翻译。真正的历史价格和合成样本范围不因语言改变。

2026-11-17 隔离 Edge 在 1440 与 390 CSS 像素、deviceScaleFactor=1 下，分别完成两种语言的市场列表、详情、方法与成交规则、模拟买入、卖清、ARK 披露研究、人物列表、经理问答及安装/券商/离线页，共 36 项检查。英文基金页面的一方资料未检出中文；切换后金额与草稿保留、账本未增加交易，刷新记忆生效。模型问答使用明确的测试替身验证语种和接口；没有借此声称新的付费模型质量或实体手机麦克风验收。

工作室独立验收另覆盖 1440/390/320、切换期间不发 POST、引导与历史不变、录音停止且转写保留。所有测试均使用临时账户或内存库，不连接真钱。

## 与 Maya 说话

打开网页并点「和 Maya 说话」，说完再按一次停止。转写先进入编辑框，发送前可改基金名称、代码或风险描述。识别过程中可以取消。拒绝麦克风权限时，键盘输入框自动获得焦点。开口前会停止上一段朗读，语音发问默认朗读新回复，用户关闭自动朗读后保留其选择。

私有工作区优先用服务器上的 Whisper small 识别。Mac、手机或笔记本连接到远程工作区时，临时录音在工作区服务器处理，处理完成后删除。本地识别器使用少量金融词作听写提示，原始转写可直接校对。浏览器语音作为替代路径，处理方会在录音时显示。

2026-11-18 在隔离的 Edge 浏览器，用中英文合成音轨逐步验证。中文听写出「惠灵顿基金」「股债平衡」，英文保留 VWELX。提出下期配置、索取历史回测、只看基金资料，三条真实 Hosted 回复分别引导至运营页、历史研究方案、普通基金详情。在这三次对话中，点击继续均未下单。浏览器为中英文回复均报告朗读开始，本机列出的系统语音只有中文，真人听感和不同设备口音仍需现场核对。[完整运行与语音对照样本](../release/review-web/voice-and-routing.json)
