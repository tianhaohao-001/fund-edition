## 现行网页用词

发起人在 11 月 18 日的网页走查中退回了「基金班底」及原折页标志。本轮采用单数 **Fund Edition**，中文界面用中文类目解释用途。中文专名暂不定案。

品牌首次出现时配「你的 AI 投资团队」或 “Your AI investment team”。Fund 指基金，Edition 表示一种可研究、可调整的方法版本。名称本身没有传达 Agent 的行动能力。首页、分享标题与产品介绍应让访客立即认出谁可以回应。进入工作室后，用户说目标、经理组织研究分工。进入策略空间后，用户提出问题、研究角色给出依据，可继续追问。当期决定可以查到提出者、质疑方、经理结论和模拟执行回执。用这些可操作的证据兑现品牌定位。

| 访客的意图 | 中文界面 | 英文界面 |
| --- | --- | --- |
| 组建属于自己的投资团队 | 自建 AI 基金 | Build an AI fund |
| 找一支感兴趣的 AI 基金 | 挑选 AI 基金 | Explore AI funds |
| 与投资人的方法展开对谈 | 名家风格基金 | Investor-inspired funds |
| 看 AI 怎样根据公开资料重建基金策略 | 热门主动基金 | Popular active funds |

在进入对话之前说清角色与来源。在对话中让人看到人物方法的具体取舍。市场基金使用原基金正式名称和代码，历史比较中标示规则组合、时段和可核资料。新的入口文案避免使用容易被误读为仿冒或产品代销的「复刻」。[现行设计规范](design/public-web.md)

## 名字与标识

「班底」是会一起做决定的人。自建时，访客可以告诉经理想法、招募同事、追问决定。选现成策略时，也可以认识研究这个策略的班底。Fund Editions 指可以亲手创作、根据公开方法重建和逐项比较的策略版本。英文首屏紧邻类别名称和两个操作，让访客知道在这里能实际做什么。

标识由**两片等量的折面和中间一线透光**组成。两片共享折痕和视角，表面可随场景显出倒影。应用图标与页头用同一轮廓。压缩到 16 像素时仍应分辨两片与中缝，在白底与深底均可辨认。单色图形即可读出，动效与反光仅用于较大画面。两种工作环境沿用同一字级、边缘曲率、玻璃厚度、焦点与按压反馈。

大厅采用白和中性灰。工作室保留经理的真实肤色和桌面光线，用席位、声音和人物的动作解释团队状态。策略区使用票据、刻度、基金代码和净值图，数据色须有文字、符号或线型辅助。按钮及焦点不应盖住人脸与数字。正式样式与动效由专任设计总监维护。[双入口视觉规范](design/public-web.md)

## 工作室语气与语音

Maya 第一人称说明自己的职责，让用户一次回答一件事。推荐回答以用户的第一人称写成完整且能直接发送的一句话，和资料入口、资金授权分开。问候、失联提示、例句及逐席发言各有实际来源。

| 场景 | 中文 | English |
| --- | --- | --- |
| 经理身份 | Maya · AI 基金经理 | Maya · AI fund manager |
| 首句 | 如果这支基金由你做主，你希望它怎么投资？ | If you ran this fund, how would you invest? |
| 目标示例一 | 我想找现金流持续增长的企业。 | I want to find businesses with growing cash flow. |
| 目标示例二 | 我想研究开发新技术的公司。 | I want to study companies developing new technology. |
| 目标示例三 | 我想用指数基金分散投资。 | I want to diversify using index funds. |
| 语音 / 键盘 | 开始说话 / 用文字回答 | Start speaking / Type a reply |
| 等设备授权 | 请允许使用麦克风。 | Allow microphone access to start. |
| 正在收音 | 正在听 · 点按结束 | Listening · Tap to finish |
| 转写待确认 | 检查这段话，再发送给 Maya。 | Review your words, then send them to Maya. |
| 用户提交后的等待 | 等待 Maya 回复… | Waiting for Maya… |
| 播报 / 中断 | 朗读回答 / 停止朗读 | Read aloud / Stop reading |
| 无麦克风权限 | 麦克风未开启。你可以打字，或点一句建议。 | The microphone is off. Type or choose a suggested reply. |
| 未收音 | 没听清。再说一次，或用文字回答。 | We couldn’t hear you. Try again or type a reply. |
| 模型不可用且可恢复草稿 | 经理暂时无法连接。你的草稿已保留。 | The manager is temporarily unavailable. Your draft is saved. |
| 重试 / 观看已有案例 | 再试一次 / 看一段预录示例 | Try again / View a recorded example |
| 草案授权 | 确认创建模拟基金 | Confirm and create paper fund |
| 招募确认 | 确认招募 | Confirm hire |
| 留待以后保存 | 跨设备保存 / 稍后再说 | Save across devices / Maybe later |

实际状态决定动词。未取得设备权限前不得显示「正在听」。转写入编辑区后再由使用者发送。建议回答可一按发送，创建基金和交易须明确确认。存储存在冲突时说明哪一页仍保留草稿。预录案例标记生成时间与来源，真实经理连接恢复后由使用者重试。访客可在匿名状态继续体验。

## 基金目录与交易解释

| 场景 | 中文 | English |
| --- | --- | --- |
| 样本外验证 | 留出期历史对照 | Held-out historical comparison |
| 部分披露 | 已披露持仓抽样 | Sample of disclosed holdings |
| 仅有方法 | 公开方法研究 | Public strategy research |
| 合成行情 | 合成行情示例 | Synthetic market example |
| 经理入口 | 询问策略经理 | Ask the strategy manager |
| 交易追问 | 为什么这次调整仓位？ | Why did the team change this position? |
| 没有下单 | 保持现有持仓 | Positions unchanged |
| 正在等待价格 | 已批准，等待下一次报价 | Approved, awaiting the next quote |
| 已成交 | 模拟成交 | Paper trade filled |
| 查看事实 | 查看资料与日期 / 查看成交回执 | View sources and dates / View execution receipt |

「复刻」指 AI 团队据公开资料重建一部分可观察的方法。基金详情须写清证据类型、观察期、比较口径和本次具体做了什么。人物策略显示真实姓名、公开方法、AI 身份，避免把 AI 团队写成人物本人或其授权代表。买卖或查看收益时，紧邻操作写明模拟资金、估值时点和适用的费率假设。没有计算证据的条目只呈现已经完成的方法研究。新手无须理解“留出期”，界面可补一句「只用更早的资料设计，再用这段未见过的数据检验」。
