# 第一版接待流程设计研究

当前网页执行[基金班底双入口设计规范](public-web.md)。以下内容归档自单经理首屏阶段，可用于追溯当时的流程判断。

**v2 · 2026-11-18 · 专任 UI 设计总监维护**

进入大厅，只回答 Maya 的一个问题。她能带用户组建基金，也能带用户研究一只熟悉的基金。愿意自己浏览的人可在同一层看到两个去向。占位名称沿用现有版本。

## 设计责任

UI 设计总监维护字体、色板、间距、图像、动效、组件状态与评审样机。网页工程负责人实现共用组件，Studio 与 Funds 分别接入业务。Agent 负责人提供实际席位与交接事件，研究负责人签发证据，引擎负责人签发执行回执。新增界面先回答三个问题：谁在说、用户现在要完成什么、做完会回到哪儿。设计总监复核桌面与窄屏网页，产品发起人决定是否采用。[产品需求与验收](../product-requirements.md)

## 观察了什么

2026-11-18 在渲染后的苹果美国官网走完一次选用途、进入下一题、返回的短路径。另核对 iOS 官网、iPhone 使用手册及 Apple Human Interface Guidelines。我们使用了公开系统演示和手册，本轮没有可操作的实体 iPhone。

| 现场操作或官方依据 | 本产品采用的行为 |
| --- | --- |
| 苹果 Mac 选择器第一题询问用途。初始继续按钮不可用，选中日常用途后，同一处变为可以提交的 OK。 | 用户先说一个目标。停止听写后原控件转为发送，空草稿时发送不可用。[Apple · Help Me Choose](https://www.apple.com/mac/best-mac/#usage) |
| 点击 OK，页面换成与日常用途相关的一题，进度由 1/5 变为 2/5。返回按钮的可访问名称会指明上一题；返回后原用途仍处于选中态。 | 点击直接浏览才出现两个目的地；上下文中只展示一层问题。网页回退、面板返回和 Escape 共用同一层历史；回去可以修改已说过的话。[Apple · Help Me Choose](https://www.apple.com/mac/best-mac/) |
| iOS 官网展示从同一助理入口说话或打字，以及在当前内容上提出请求。iPhone 使用手册说明连续提问和修正误解的操作。 | 说话与键盘共用草稿。拒绝麦克风、未收到语音或浏览器缺少听写接口时，可当场转为键盘，继续相同任务。[iOS 官方交互演示](https://www.apple.com/os/ios/) · [iPhone 使用手册](https://support.apple.com/en-ca/guide/iphone/-iph83aad8922/ios) |
| Apple 将 sheet 用于跟当前内容密切相关的短任务，建议主界面一次只显示一层。文档区分返回上一步与关闭整个任务。 | 浏览、招募、证据在同一个原生 dialog 容器切换。背景具有原生 inert 行为并隐藏其操作，关闭返回原位置。长会议和基金曲线占正常页面。[Apple HIG · Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets) · [Modality](https://developer.apple.com/design/human-interface-guidelines/modality) |

首轮布局有四种东西在抢用户的注意力：常驻导航、基金经理输入、双入口大卡和人像／设备选稿。研究页又同时展开代码列表、曲线工具与证据操作。这里将“开口”作为首屏唯一主动作。品牌标记、经理肖像、模块名称、会议桌上的交接线均是静态信息。关闭、设置、浏览和文字链接都纳入验收计数。

## 用户如何走

| 当前任务 | 用户实际会看到什么 | 接下来发生什么 |
| --- | --- | --- |
| 接待 | Maya 的小幅肖像、身份、一句问话与一个主动作“和 Maya 说话”。“直接浏览”和设置是两个次要操作。 | 说一句“帮我建一支稳健基金”或“我想研究 VWELX”。不开麦时在原处输入。 |
| 直接浏览 | 两项同层选择。 | 组建团队，或研究市场基金与人物方法。 |
| 组队 | 一步形成任务书；也能从示例均衡配置开始。 | 确认后看工位，可用自然语言雇用新席位；返回确认稿可修改。 |
| 团队会议 | 每次看一条署名的交接，席位、收件人、状态与意见出现在同一画面。箭头直接标在桌面文件所在处。 | Theo 提交证据 → Inez 向 Maya 提出异议 → Maya 向用户归纳 → 引擎独立说明是否提交订单。依据按需展开，返回后停在原条目。 |
| 基金研究 | 自然语句可直接点名；手动浏览先选市场基金或人物研究，再逐个阅读。 | VWELX 展示原基金与配置代理同区间曲线。可向经理问回测、数据来源，再拉起具体依据。人名与方法同时出现。 |
| 设置 | 界面语言、回答朗读。 | 中英文选择保存在当前浏览器。切换语言后不提交草稿。朗读由用户主动开启。 |

## 共用视觉规则

- 画布使用偏暖系统白 `#FAF9F6`，正文深墨 `#272524`，次要文字 `#645F5A`，分隔线 `#DCD7CF`。接待与系统层主色 `#302C2B`。Studio 发言和主动作用酒红棕 `#663D43`，Funds 数据和主动作用深蓝灰 `#2C525F`。焦点使用 `#2178B0`。协议和业绩数据区域均为实色背景。
- 系统信息优先使用 `-apple-system / Segoe UI / PingFang SC / Microsoft YaHei UI`。字标使用本地衬线。桌面主问候 34–63 px，会议标题 30–60 px，详情面板 24–34 px，正文 16–21 px，辅助信息 12–14 px。代码、日期和百分比采用统一数字格式；中文按自然词组换行。
- 页面栅格为 4 px 基础序列。桌面工作区不超过 1040 px，页首横向 5vw，内容列间距 28–76 px。701 px 以上两列；700 px 及以下一列，正文边距 22 px。桌面任务面板最大宽 486 px，位于视口底部上方；窄屏底部贴合安全区。所有任务按钮至少 44×44 px。
- 接待画像使用本项目生成的虚构基金经理。裁切保留眼睛、表情和自然光，形状与线条属于联系人身份。接待首屏只出现这一张肖像；工作室切到俯视桌面与纸面资料，表现三席的位置，人名通过文字给出。基金研究去除场景照片，给基金代码和基线留出空间。
- 图表采用约 2.8:1 的宽高比，使用真实点顺序、统一坐标和少量水平基准。目标为 2.6 px 深蓝实线，配置代理为 2.4 px 锈色虚线。曲线和结论同时用标签、线型、文字描述标识，详情给观察时段与误差。样例把 2020 年底设为 100，计入 23 个留出季度；原基金终值 165.02，配置代理 158.36。实际投资与模拟执行须单独显示授权、费用和成交结果。
- 面板进入使用 240 ms 缓出动画，系统启用减少动态效果时取消。语音控件依次承载听写、停止与确认；监听状态有文字，视觉节拍仅指示“正在听”，不表示音量。即使关闭声音也能读完整个过程。键盘 Tab 局限在当前面板，Escape 回退；正文随页面缩放，长内容可滚动。
- 工作模型以真实接收事件决定“正在工作／有结果／失败”。每次交接展示发件人、接收者、可公开结论、来源、异议与执行边界。当前样机的台词标为“示意发言”，失联示例可以直达 `#partial`，等待示例可以直达 `#working`。样机实现本地草稿、交互状态和研究材料，实际 HarnessRouter 模型、麦克风收音和模拟成交要在功能网页上另外验收。

## 可操作项预算与验收

在 Edge 分别按 1440×900、390×844、320×680 三个 CSS 视口走完 25 个同样的状态，共 75 条计数。统计当前表面所有可激活按钮、链接、输入框和选择控件，也记录已禁用项及视口内数量。原生模态窗口打开时，背景不可操作。所有测量中，视口内可激活项数与当前表面全部可激活项数相同，均未出现横向溢出。高清 PNG 以 1.25 倍像素输出。

| 状态 | 全部可激活项 | 主按钮 |
| --- | ---: | ---: |
| 大厅、小组队引导、招募发问、团队工位 | 3 | 1 |
| 直接浏览、设置、研究分类 | 3 | 0 |
| 已输入／已听写而待确认，含输入框本身 | 3 | 1 |
| 空文字草稿 | 2，另有 1 个禁用的发送按钮 | 0 |
| 确认任务书、收到招募、回测方法、经理回答 | 2 | 1 |
| 研究席、风险席、经理、独立执行回执 | 3 | 1 |
| 发言依据 | 1 | 0 |
| 主动基金目录、人物目录、基金与人物详情 | 3 | 1 |
| 披露材料中间页／最后一份 | 3／2 | 1／0 |

还验证了浏览器回退保留消息、中文切英文并刷新、离线打开 HTML、浏览器未提供语音识别、权限拒绝、研究来源链接，以及用测试替身传入听写结果后修改基金代码再确认。三种视口是网页模拟；本次没有用实体 iPhone 或真人麦克风做收音测试。样机目录使用 8 个市场策略和 5 个投资人物的本地快照；正式目录可增加标的，视觉和交互预算适用相同规则。
