# 我的投资组合

从页头的「我的投资组合」、自建基金办公室或展馆基金详情进入。新访客的钱包有 US$100,000 模拟现金，可以持有多只自建基金、名家风格基金和热门主动基金策略。注册会接续当前访客的本金、持仓、单据和工作室，随后可在另一台设备登录。

在工作室确认首只自建基金时，钱包按可用现金全额申购这只基金。此前在展馆申购的份额继续持有。例如，确认团队时还剩 US$85,000，首笔投入就是 US$85,000。余额为零也可建团，随后在组合页申购。新增第二只及更多基金时，由用户选择投入金额。旧钱包保留原本金、持仓和回执。此前已创建的基金继续沿用原账，不补记首笔入资。

在组合页展开领取入口并确认，每次可增加 US$100,000 模拟现金。现金留在钱包，直到你选择基金并确认申购。每笔领取可在「资金与交易记录」中查看。组合盈亏等于总权益减去初始本金和累计领取金额。若确认后断线，重新核对会使用原请求编号，同一笔款项只入账一次。

## 份额与计价

| 基金 | 模拟净值的依据 |
| --- | --- |
| 自建基金 | 基金自身模拟账本权益相对初始权益的变化，以每份 100 美元起算。账本估值随基金自己的模拟运行更新。 |
| 巴菲特风格 | 2017 年 AZO 研究归档的期末权益。2017-12-29 每份为 103.87 美元。 |
| 其余目录策略 | 各自已经完成的历史代理研究、历史价格规则实验或合成情景，详情与成交单均显示日期及来源。ARKK 的每份 106.56 美元来自 2026-09-08 标签的合成情景，与原基金实时市价无关。 |

报价以美分为单位，基金份额精确到百万分之一。申购最少 1 美分，且必须足以形成有价值的份额。确认单锁定报价与估值日，净值变动则重新确认。份额按预算向下取整，扣款按买前买后持仓估值差四舍五入至美分。赎回按模拟份额结算，当前费用为零。组合权益为共用现金加各项份额估值。本账户只产生模拟申购或赎回，不会连接券商下单。

旧版目录曾为每项研究单独开一个模拟账户。参加过的旧账户保存在组合页「历史独立模拟账户」，可查原始现金、份额、估值、来源与历史回执。各份旧本金不累加进统一钱包。没有旧账的访客直接看到新钱包。从工作室选择对应办公室，可查看该基金的内部交易记录。

## HTTP 与复验

`GET /api/portfolio` 返回当前浏览器或账户的余额、产品、持仓、最近 100 项回执与只读旧账。使用 `?before=<olderOrdersCursor>` 读取更早回执。`POST /api/portfolio` 接受唯一 UUID 的 `requestId`、`productId`、`side`，申购传 `amountCents`，赎回传 `unitsMicros`。前端确认同时传 `expectedNavCents` 和 `expectedAsOf`。重复提交同一指令与编号得到原回执，复用编号改指令会收到 HTTP 409。SQLite 把现金、份额和回执写进同一事务。

领取入口调用 `POST /api/portfolio/claim`，提交当前工作区的 `workspaceRef` 与唯一 `requestId`。服务端固定每次领取 US$100,000。返回的回执以 `side: claim` 和 `kind: paper-cash` 标识，钱包同时返回累计领取的 `claimedCashCents` 和累计本金 `contributedCashCents`。相同请求编号重试会返回原回执。
