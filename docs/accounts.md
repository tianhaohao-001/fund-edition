# 网页账户与历史模拟账本

从网页大厅注册或登录。使用常用邮箱和 12 至 128 个字符的密码。首次注册可接续当前访客浏览器中的工作室、纸上账户、基金持仓和已确认的研究。再次登录可在连接同一个后端的其他浏览器恢复这些内容。切换到已有账户时显示该账户自己的记录。退出会撤销当前浏览器会话，其他已登录设备可继续使用。

本地运行时，注册资料和账本保存在 `FUNDROOM_DB_PATH` 指定的 SQLite 文件。默认在 `.fundroom/fundroom-v1.sqlite`。用相同源码启动两个独立数据库会产生两套账户。网页可以用 HTTP 访问本机回环服务，公开部署需在 HTTPS 站点源上运行。当前使用本地密码登录。Apple 客户端沿用独立的临时配对身份，券商操作员使用独立口令。

## 演示一笔可以追问的交易

1. 在大厅告诉 Maya “帮我研究并复刻 Vanguard Wellington Fund，代号 VWELX”。
2. 核对研究对象与历史规则。确认建立模拟复刻基金时会分配 10,000 美元模拟资金。纯研究确认只生成实验报告。
3. 打开基金的第一张回执。基日为 2020-12-31，两组研究单位都以 100 开始，按模拟成交额计 5 个基点成本。VYM 和 VCIT 的初始目标权益 / 债券比例为 65% / 35%。这是基于发布方季度总回报的固定组合，所有价格和数量标注为历史归一化研究单位。VWELX 是比较对象。
4. 问 Maya “为什么买这两项？扣完成本还有多少现金？” 指定回执时，服务器向经理提供该基金此笔实际模拟明细、成本、授权检查与交易前后现金。问答不改变持仓。选择推进一季可按下一个历史观察点调整账户。历史样本结束后停止。
5. 可以对 Maya 说 “招一名风控分析师，职责是检查集中度”。经理从真实的可选候选人中提出职责，确认聘任才加入团队。

## 接口

| 接口 | 用途 |
| --- | --- |
| GET /api/auth/session | 当前网页账户，访客返回 user=null |
| POST /api/auth/register | JSON 提交 email、password，可选 language；新账户继承当前访客模拟记录 |
| POST /api/auth/login | JSON 提交 email、password，恢复本人账本 |
| POST /api/auth/logout | JSON 提交空对象，撤销当前浏览器会话 |
| POST /api/action | concierge、prepareResearch、confirmResearch、sendChat、confirmHire、runScenario 等操作。操作方为当前会话，请求需带 requestId。 |
| GET /api/state | 当前工作区、研究草案、研究记录、基金持仓与成交 |

浏览器按同源发送请求。账户写请求需浏览器提供同源 Origin 及 application/json 并使用 HttpOnly、SameSite=Strict Cookie。密码采用随机盐与异步 scrypt 派生，登录令牌只存摘要，有效期 30 日。本地失败计数同时针对邮箱及来源地址，窗口 15 分钟。库中只有模拟用户账户；邮箱没有发信校验和重置密码流程。样例凭据留空，真实密钥放在本机环境。

本地测试 `node --test --test-isolation=none test/accounts.test.mjs`。完整套件 `node --test --test-isolation=none test/*.test.mjs`。测试创建临时数据库，并注入测试模型。

## 历史研究团队与实况

先完成 `confirmResearch`。从报告点击团队评审会调用 `reviewResearch`，由研究席和风险席分别经 HarnessRouter 阅读同一份历史数据、公开来源与分歧最大的观察期。两份公开观点交给 Maya 汇总。研究席和风险席都未成功时，经理会显示未启动。部分席位失败时可点重试，复用同一语言、同一证据快照中已经成功的回执。

`GET /api/team/activity?requestId=<本次操作编号>` 可读取本人工作区内正在进行的评审、交接或引擎核验。完成的运行可从 `run.activity`、`researchReviews[catalogId].activity` 查看。只展示岗位任务、公开业务意见、证据引用和回执。会话撤销后，正在等待的模型回复不能写回之前的账户。
