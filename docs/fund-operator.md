# 让 AI 基金团队决定下一期

从基金广场选择任一市场基金，点「让 AI 团队决定下一期」或「让团队评估下一步」。也可以直接进入 [VWELX 模拟运营](http://127.0.0.1:3331/fund-operator.html?fund=wellington&lang=zh-CN)。语言参数可选 en-US。

每只基金各有研究席、风险席、基金经理 Maya。前两席各自读取截至会议开始时登记的公开风格、授权、数据缺口、模拟账本和最近公开收盘记录。经理随后收到两份有来源编号的意见，选择维持仓位或提交具体目标、理由和重新评估条件。风险席否决调仓时，经理仅能提议维持。独立规则引擎校验通过才封存。会话之外的账户无法读取或批准本次决定。

VWELX 可在股息股票 VYM 和信用债 VCIT 两个代理之间调整。股票目标范围 60% 至 70%，债券占余量。PSTKX 和 JEPI 可研究 VOO 股票敞口，无法表示债券超额或 ELN 收益。其余市场基金仍可独立开会并给出观望意见。完整期权、股票和个券数据需要额外接入。模拟盘从 10,000 美元现金开始，各基金的账本独立。

## 从建议到成交

1. 点「让团队决定下一步」，现场查看每席开始、结束和向经理交接。三席的有效回复都会保留 HarnessRouter 回执；一席失败则保留失败活动并停止。成功决定按内容计算 SHA-256 封存。本市场日内，每只基金只封存一项有效决定。
2. 阅读 Maya 对目标仓位、分歧与复核条件的解释。可以展开「向 Maya 追问这次决定」，例如问“我的模拟账户已经买入了吗？”。回答来自一次单独的 HarnessRouter 调用，使用本人的封存意见、授权、实际持仓和收据。转写可编辑，回答可朗读。这条接口只写对话记录。
3. 用户须在封存当日单独确认。选择持仓不动会生成一份明确的纸盘记录。批准调仓则锁定下一个完整美股交易日，以 Nasdaq 当天未复权的 ETF 每股收盘参考价做本地模拟。页面允许在成交前撤销；重复操作不会追加成交。模型不能指定成交价、现金余额、数据源或成交日期。
4. 在约定收盘发布后点「查看收盘与结算」。独立引擎核对全部成分日期、来源和授权，先卖后买，使用百万分之一份及美分记账，买卖按成交额各计 5 个基点并向上取整到美分。不完整数据保留待结算，一直等到下一次美股收盘刷新后仍未核账的授权过期。纸盘没有券商订单。
5. 当成交日取得同源 VWELX 净值，另行锁定下一交易日作为评价日期。只有评价日同时取得原基金及全部成分的同日美元收盘，才比较该次成交后组合和 VWELX 的收盘价格变动。双方均排除分红再投资、现金利息和税。多数个股或基金缺少匹配数据，目前不会生成同口径比较。后续业绩不进入原来的决策输入。

依据资料的 referenceDate 是资料描述的报告期。verifiedAt 是实际核验日，系统同时记录本次服务实际加载资料的时间。运营 API 以服务器当前时间开始，拒绝客户端传入历史截点、目标权重或行情。现有 VWELX 固定权重历史实验与 PSTKX 价格对照有独立入口；当前无历史 AI 盲演成绩。

## 真实记录与重复验证

- [三席现场决定和用户授权](../release/review-web/forward-hosted.json)记录 2026-11-18 的隔离验收账户。Maya 选择 VYM 60%、VCIT 40%，批准后等待 11 月 19 日收盘。账户仍是 10,000 美元现金，持仓和成交为空。
- [另一次三席现场决定和只读追问](../release/review-web/forward-hosted-dialogue.json)包含最多六个带日期的收盘观察和真实问答。提问前后锁定决定、订单和仓位完全相同。
- [失败会议](../release/review-web/forward-hosted-incomplete.json)中独立风控席的回包未满足结构要求，Maya 跳过，账户仍是全现金。
- [确定性回归测试](../test/fund-operator.test.mjs)用明确标为替身的两份经理判断分别给出 60/40 与 70/30，并用人造下一收盘观察验证两种仓位不同、费用与现金守恒。另行验证数据截点、拒绝越权、撤销、幂等、跨账户和重启隔离。测试价格用于验证记账逻辑。

本地执行 `node --test --test-isolation=none test/fund-operator.test.mjs test/market-freshness.test.mjs`。配置既有的 HarnessRouter 环境后，`node scripts/verify-forward.mjs` 会向真实服务发起一场三席会议与一次经理追问，将脱敏结果写入独立验收文件。该脚本自建临时内存账户。
