### 下一班如何接手

产品负责人交付可访问的演示、主办方发新公告、团队准备发布或最后提交时复查。本记录为人工触发交接。

1. 同一时段打开项目榜、社交页、全部论坛及 Build log 筛选页，记绝对太平洋时间。在此档追加带时间的快照，保留本次基线。将公开项目卡与已正式提交的条目分开记录。
2. 更新项目增减、首两名票差、新的已验证收入项目、关联帖数和单帖表现。按社交卡的项目归属汇总。另查新增项目及我方最终参赛名称。
3. 检索论坛所有分类的 Build Log 标题。核对 OpenHarness 标签、Sentinel 日志变更、新作者的运行证据，标明主办方是否确认其参赛资格。
4. 遇到领跑者易位、截止或规则变更、新的同类对手、日志资格变化，或我方首次上榜，给比赛负责人报时间、旧值、新值及原页链接。用户可试用时将最新竞品行动同步营销负责人。
