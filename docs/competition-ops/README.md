## 收到“产品好了”时

1. 情报和运营同时刷新三类榜与主办方最新通知，标出自上次以来值得改变决定的事实。核对离提交窗口还有多久。优先保障提交材料齐备。
2. 增长负责人从全新访客视角走一遍当时对外的英文入口、核心案例和视频，记录版本、访问时间，以及评委能亲自复核的结果。对照主张更新草稿。
3. 总监汇总已验证的项目名、参赛链接、视频、实际 Harness ID、Build Log 与首帖供 Hao 审阅。正式提交后以回执和公开项目卡作为投票入口。对外发布、邀测和提交均按届时授权执行。
4. 开始试用后分别记录邀请、打开、完成、理解规则、可引用反馈及实际投票数。总监依据最新数据决定次日资源投向。比赛门户或发帖渠道出现的新情况追加到对应记录。

跨会话接手时先读本页与三个专岗文件。子代理在活跃任务中可相互发消息，待命期间以共享文件保存已验收的工作，下一次启动重新联网取数。
