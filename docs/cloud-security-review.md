## 2026-11-18 完整网页运行包

目前与桌面完整版共用网页和服务端的产物是 `release/cloud/full-web/fund-edition-web.tgz`。部署参数详见[完整包运行说明](../hosting/cloud/full/README.md)。包内清单逐项记录网页、服务与决策模块的 SHA-256。打包后可以运行 `node scripts/check-full-cloud.mjs` 对照当前源码，再对解包实例验收。提供本产品服务器密钥并追加 `--live` 时，验收会实际请求一次巴菲特经理。运行日期、同版包哈希和真实问答回执在[解包验收记录](../release/cloud/full-web/verification-live.json)。

访客可以在自己的工作区从 Maya 建团，招募或调动员工，与员工和名家风格经理对话，运行模拟决策。只有账号转换或实际账单操作会进入相应身份流程。访客和登录用户的全部模型席位均在同一专用库内预留站点小时和滚动 30 天额度。访客同时计入首聊额度，重试已经提交的同一回执可直接读取。服务器入口只接收网站专属模型密钥及选定配置，券商、付款和桌面凭据均不向完整包传递。数据库以持久卷保存，运行单副本。反向代理转发时一组来访流量可能共用网络额度；此时该上限保护整个入口。

本轮检查覆盖生产模式的访客与跨来源边界、包内容、本地进程重启、模拟账户和真实模型回执。托管商的 TLS、硬盘备份恢复和最终公网域名需在实际环境再验。

### Node 托管候选的访客接待

在 `FUNDROOM_PUBLIC_HOSTED=true` 的固定 HTTPS 来源，访客可先与 Maya 交谈八次。第九次会保留未发送的话并提供登录入口。成功请求的回执可重读，重试相同回执不另耗额度。用户确认创建、交易、跨账户数据和订阅仍分别经过工作区或账单身份检查。公开 Sites 与独立 Node 应用有各自的运行配置，以上验收没有发布新版本。[浏览器端从访客走到购买](../release/review-web/qa-membership-3386/hosted-guest-checkout.json)

Node 在 SQLite 中记录已预留的访客调用。每访客最多八次模型请求、十六次语音识别；同一网络标识一天最多 24 次模型请求和 48 次识别。站点模型滚动 24 小时默认 80 次，`FUNDROOM_GUEST_AI_DAILY_LIMIT=0` 可暂停；识别预算为该数值的两倍。模型另受原有小时限额及并发限制，工作区听写单并发、每段最多 30 秒。网络标识采用服务器实际看到的连接地址按 UTC 日期散列。处于同一反向代理后的访客可能共用网络额度。登录、模型额度与支付签名还需在真实公网入口正式发布前复验。

2026-11-18，本轮只检查开发机上的候选代码、临时账本和构建包。模型回归使用测试回应，既有真实调用另列出处。当前决定为**可本地审阅，暂缓公开部署**。发起人要先验收前端，并且云账户、正式入口和平台费用上限尚待验证。

## 放行前仍需取得的证据

1. 在发起人选定的免费云账户里确认持久卷能够恢复同一访客记录，验证 HTTPS 和出站网络允许应用直接到 HarnessRouter。通过真实公网问答与追问核对两个回执。为服务器配置独立、可撤销的密钥，核对供应商后台费用上限。
2. 核对免费云服务的边缘网络防护、该方案可用的用量硬限和告警、备份和还原，以及资源配额下的实际延迟。IP 配额只采用可信入口提供的信息；若多用户共用入口地址，仍可能共同触发限流。免费账户未建立，这些项目尚无生产验证。设备模型预算仅覆盖独立应用的这些指定文件，其他 HTTP 响应、CPU、存储及模型平台用量各由对应平台结算。[Railway 费用控制](https://docs.railway.com/pricing/cost-control)
3. 发起人确认前端后，按照最后验收的 Worker 重新打包、核对摘要，再发布。此次应用安全审阅和小规模功能并发验证未测得公网大流量承载能力。
