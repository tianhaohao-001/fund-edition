# 巴菲特风格委员会的历史输入

这是一项单标的历史决策实验。团队在四次会议中分配 AutoZone（NYSE: AZO）和美元现金，基准从相同的首个可成交开盘起持有 AZO。研究标的在计算收益前确定，当时已有经营多年并披露年报的汽车零件零售业务可研究。2017 是 WIKI 行情档案最后一个完整日历年。

## 财务口径与修订

AutoZone 的前三个财季各 12 周，最后一个财季为 16 周。第一至三轮的滚动 52 周收入、净利、营业利润、资本支出均用上个完整财年的金额，加本期 12、24 或 36 周累计数，再扣上年可比期间。稀释股数按周数加权，估计每股收益由同期净利除以滚动稀释股数得到。期内股权激励税务处理和回购会影响跨期 EPS 解读。

初步数据质检发现一个列报差异。2016 年报将 6,373.1 万美元期权行权的超额税收收益列在融资现金流，而第一季报脚注已公开说明，采用 ASU 2016-09 后将其列入经营现金流，并相应重分类上一年比较数。因此在滚动计算时，将 FY2016 已披露经营现金流 15.77329 亿美元加上 0.63731 亿美元，再与各季当时的报表衔接。这个修订在委员会产生有效决策前完成。[原年报现金流量表](https://www.sec.gov/Archives/edgar/data/866787/000119312516745160/d253831d10k.htm) · [第一季报附注 A](https://www.sec.gov/Archives/edgar/data/866787/000119312516793056/d242685d10q.htm)

自由现金流近似扣除全部设备和物业支出。巴菲特讨论的所有者收益要求估计维持业务所需的投资及营运资金，公司的合计资本支出还包含扩张投资。模型可以质疑这个近似。其余投资方法根据巴菲特关于可理解业务、未来现金流、价格与安全边际的公开说明概括。[1986 年股东信附录](https://www.berkshirehathaway.com/letters/1986.html) · [1992 年股东信](https://www.berkshirehathaway.com/letters/1992.html)

## 行情与可重复性

冻结数据从 Quandl WIKI Prices 公共领域档案抽取，归档镜像固定到版本 1。原始开盘与收盘价用于两边记账。范围内可观测记录的拆股因子均为 1，除息金额均为 0。2017-11-08 原档缺一个交易日，两边一起跳过当天估值，日度最大回撤仅覆盖可观察收盘点。2017-07-03 与 2017-11-24 按交易所安排在 13:00 提前收盘。档案为后来冻结的价格历史，逐日第一版文件和逐笔时间戳不可得。`closeAt` 表示交易时段结束，`availableAt` 使用供应商公布的工作日 21:15 更新安排。该源在 2018-04-11 停止主动维护。[Nasdaq 的数据说明与公共领域声明](https://data.nasdaq.com/databases/WIKIP) · [归档镜像](https://www.kaggle.com/datasets/marketneutral/quandl-wiki-prices-us-equites) · [NYSE 2017 年日历](https://ir.theice.com/press/news-details/2016/NYSE-Group-Announces-2017-Holiday-and-Early-Closings-Calendar/default.aspx)

运行产品和测试可直接使用已冻结的 `history.json`。如需重新抽取，运行 Python 3.11 或更高版本的 `python data/buffett-study/build.py`。可通过 `--cache` 指定原始档案缓存，通过 `--out` 写入新的验证副本。首次运行会下载约 463 MB 市场档案，访问 SEC 时可将 `SEC_USER_AGENT` 设置为实际联系人。Windows 上 Python 若缺少纽约时区数据库，安装 `tzdata`。生成器核对行情压缩包 SHA-256；年度初报数值按原始 Exhibit 99.1 的全年列录入。研究只随产品分发所用事实、日期、价格和独立概括。

本次发布使用版本 `2017-asu2016-09.1`，规范 UTF-8/LF 的 `history.json` SHA-256 为 `93fdd69f20e8dbe73e282cbf296b18d6d7f81cc4541c4818528f4c211a8283d8`。匿名化输入可以减少模型认出公司的机会，仍可能有来自预训练的历史记忆。
